# React To-Do List App

A modern and simple To-Do List application built with React.

## Features

- Add new tasks
- Delete tasks
- Change task status
- Filter tasks
- Search tasks
- localStorage support

## Technologies Used

- React
- SCSS
- UUID
- localStorage

## Installation

```bash
npm install
npm run dev
```

## Future Improvements

- Dark mode
- Edit tasks
- Drag & drop
